# p6-1e-sync preparation

Branch `m6e-p6/sync`, based on 4110e90366 (plan base cb002d4874). Four commits, all "M6E P6.p6-1e-sync: ...". 384 files deleted, 202 edited, 1 added (587 files changed). Nothing was built or run; checks were `node --check` on edited JS, YAML/JSON parses, and `git grep` for every deleted basename (all hits resolved or listed under notDone).

## Decisions

- UIState boundary (report section 9, Option B): `services/sync/modules/UIState.sys.mjs` was moved, stripped of Weave and sync events, to `services/fxaccounts/UIState.sys.mjs` (new `EXTRA_JS_MODULES` entry, URL `resource://gre/modules/UIState.sys.mjs`). All 20 importers only changed URL. `syncing`, `lastSync` and `syncEnabled` fields are gone; no staying code read them. `tools/lint/extra-js-modules/allowlist.txt` got the new path in place of the old one. 1f deletes this file with the rest of the UIState consumers.
- `FxAccountsCommands.sys.mjs` (Send Tab / Close Tab, built on Sync crypto and TabsStore) is reduced to a stub class (`availableCommands()` returns `{}`, `pollDeviceCommands()` no-op). `AccountsGlue` lost the `open-uri` / `close-uri` observers. 1f deletes the stub.
- `sync_merge_dialog.clicked` Glean metric (used by `FxAccountsWebChannel`) moved from the deleted sync `metrics.yaml` into `services/fxaccounts/metrics.yaml`, so the FxA code and test keep working until 1f. The four `fxa.sendtab_*` / `closetab_*` metrics were removed (they only went to the `sync` ping).
- `sync.ftl` was NOT deleted (the report said delete): `FxAccountsWebChannel` loads it and the FxA app-menu DOM uses its ids. 1f deletes it.
- `test_sync_utils.js` (tests `PlacesSyncUtils`, which stays) and its two fixtures were kept in `toolkit/components/places/tests/sync/` with a trimmed `head_sync.js` and `xpcshell.toml`; the 14 mirror tests and sqlite fixtures were deleted.
- `webrtcUI.sys.mjs` got a small private `EventEmitter` class instead of `toolkit/modules/EventEmitter.sys.mjs`: the toolkit one passes the event name as the first listener argument, the deleted syncedtabs one did not (the report's "same API" claim is wrong).
- `BrowserUtils.getShareableURL` scheme list is now a constant set; the `services.sync.engine.tabs.filteredSchemes` pref is gone.
- `webextensions.storage.sync.kinto` and `serverURL` prefs deleted; `Extension.sys.mjs` and `ext-storage.js` now always use the Rust `ExtensionStorageSync`; `ExtensionStorageSyncKinto.sys.mjs` and its tests deleted.
