# Phase 6: unreachability proof for what stays (D30)

Spec D30 and the plan's Phase 6 "Done when" require that anything left of a dormant feature is unreachable: locked pref, no listening socket, no network traffic, no entry point from web content or IPC. This table lists every kept item and the evidence for each property, checked against `origin/main` on 2026-10-29 (paths are repo-relative; `m6e.js` is `browser/app/profile/m6e.js`).

- **PROVEN-STATIC**: the source shows all four properties (or shows that a property does not apply because the feature is a live local one).
- **NEEDS-RUNTIME-CHECK**: the source is not enough; `tools/m6e/unreachability_check.py` observes the missing fact. Not run yet (no build exists).
- **REACHABLE**: a real finding, described under "Findings".
- Network is also covered end to end by `tools/m6e/acceptance.py` check 3 (`check_network`, idle capture of nsHttp and nsHostResolver, host list `ALLOWED_HOSTS` at line 76). Viaduct, the Rust HTTP client, goes through necko, so that capture sees Rust traffic too. Check 6 (`check_removed`, line 1386) already asserts `REMOVED_PREFS` (134), `REMOVED_CONSTANTS` (188), `REMOVED_ABOUT` (196) and the Settings groups; check 9 (`check_hardening`, line 1930) takes a TCP-listener snapshot of a plain headless launch. None of that is repeated here.
- Searches used: `git grep` for `ServerSocket|createServer|.listen(|nsIServerSocket` over the directories of each item (no hit anywhere in the kept code or in the Rust crates, except the dev-only `nimbus-cli/src/output/server.rs`, not linked); `git grep` for `fetch(|XMLHttpRequest|RemoteSettings` per file; the registrations `toolkit/modules/ActorManagerParent.sys.mjs`, `browser/components/DesktopActorRegistry.sys.mjs`, `docshell/base/nsAboutRedirector.cpp`, every `*.ipdl`/`*.ipdlh` and `*.webidl` (names searched: nimbus, fxa, relay, backup, quicksuggest, ipprotection, vpn, sync15, bits, pingsender, crashmonitor, selectableprofile).

## Where the brief and the tree disagree

- `FirefoxRelay.sys.mjs` is the full 867-line module with its token getter stubbed, not a small stub (row 20).
- `services/crypto` has no WeaveCrypto; it holds `utils.sys.mjs` and `jwcrypto.sys.mjs`. `FxAccountsCommon`, the `identity.sync.tokenserver.uri` pref and the urlbar `AI_CHAT` plumbing no longer exist.
- `sync15` and `tabs` are in libxul only as dependencies of `logins`; `sync_manager` and `fxa-client` are not linked (row 6).
- `ONNX_RUNTIME` and `--with-onnx-runtime` are gone from `toolkit/moz.configure` (p62d); only CI tasks remain.
